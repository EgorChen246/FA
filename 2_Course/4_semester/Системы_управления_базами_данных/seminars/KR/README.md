### Варианты заданий

#### Вариант 1. База данных «Библиотека вуза»

В базе данных хранятся сведения об изданиях, читателях, структурных подразделениях (к которым относятся читатели), сроках сдачи изданий и др.

**Пользователи:** администратор, методист, библиотекарь.

- **Администратор** – добавляет/удаляет/редактирует пользователей системы, имеет неограниченные права на другие действия с базой.
- **Методист** – определяет пакеты изданий для разных курсов и департаментов.
- **Библиотекарь** – выдает издания читателям и фиксирует сроки их сдачи.

**Правила:**
- Студент не может получить новое издание, пока не сдаст просроченное.
- В начале учебного года библиотекарь выдает пакет учебных изданий студентам каждого курса сроком на 1 год.
- Для преподавателей сроки сдачи изданий не определены.

**Хранимые данные:**

- **Об изданиях:**  
  код, наименование, автор, тип (книга, учебное пособие, журнал, газета, методические указания), срок для прочтения студентом (книги/учебные пособия – 1 месяц, журналы – 2 недели, газеты – 5 дней, методические указания – 1 месяц), город, издательство, год издания, количество страниц, ISBN, общее количество, количество свободных экземпляров, признак выдачи на 1 год (если да – указанные сроки не действуют).

- **О читателях:**  
  категория (студент/преподаватель), ФИО, номер телефона, дата рождения, номер читательского билета, номер студенческого билета, номер зачетной книжки, группа (для студентов), курс (для студентов), должность (для преподавателей), департамент (кафедра), факультет, список удерживаемых изданий со сроками их сдачи.

- **О пакетах изданий** для выдачи студентам различных курсов и кафедр (департаментов):  
  каждый пакет содержит набор определенных изданий; издания в пакетах для разных курсов и разных департаментов различны. Каждый студент определенной группы получает один и тот же пакет изданий на 1 год.

- **О пользователях:**  
  роль, логин, пароль.

#### Вариант 2. База данных «Расписание занятий»

Хранятся сведения о распределении занятий в вузе по преподавателям, дням, парам и аудиториям на один семестр.

**Пользователи:** администратор, методист учебно-методического управления, сотрудник департамента.

- **Администратор** – добавляет/удаляет/редактирует пользователей системы, имеет неограниченные права.
- **Методист** – может вносить изменения в любые элементы расписания.
- **Сотрудник департамента** – может вносить изменения только в расписание преподавателей своего департамента.

**Хранимые данные:**

- **О группах:**  
  наименование, курс, семестр, департамент, факультет.

- **О преподавателях и сотрудниках департаментов:**  
  ФИО, должность, департамент, факультет, читаемые дисциплины и виды занятий по ним (лекции, лабораторные, практические) – для сотрудников не заполняется.

- **О дисциплинах:**  
  код, наименование, курс, семестр, преподаватели.  
  Каждая дисциплина может быть закреплена за несколькими преподавателями. Определенный вид занятий может вести только один преподаватель.  
  *Пример:* по дисциплине «Алгоритмы и структуры данных» лекции ведет Мишин Е.А., лабораторные – Петров И.И. (лабораторные не могут вести два преподавателя одновременно). Если есть практические занятия, их может вести Петров И.И.

- **О расписании:**  
  день недели, четность, номер пары, дисциплина, вид занятия, преподаватель, группа, номер аудитории.

**Ограничения:**  
- У студентов – не более пяти и не менее двух пар в день, не более одного «окна».  
- У преподавателя – не более 4 пар в день, не более одного «окна» (два и более подряд запрещены).  
- В одной аудитории на определенной паре – не более одного занятия.

- **О пользователях:**  
  роль, логин, пароль. Для сотрудников департаментов роль задается.

#### Вариант 3. База данных «Нагрузка»

Хранятся сведения об учебной нагрузке преподавателей департамента.

**Пользователи:** администратор, ученый секретарь департамента, преподаватели департамента.

- **Администратор** – добавляет/удаляет/редактирует пользователей системы, имеет неограниченные права.
- **Ученый секретарь департамента** – может вносить любые изменения в базу данных.
- **Преподаватели** – могут вносить изменения в свою собственную нагрузку.

**Хранимые данные:**

- **О преподавателях:**  
  ФИО, должность, ученая степень, доля ставки (0.25, 0.5, 0.75, 1), читаемые дисциплины и виды занятий по ним с указанием количества часов по каждому виду занятий для каждой группы студентов, общее количество часов.

- **О группах:**  
  наименование, курс, семестр, департамент, факультет, учебный план.

- **Об учебных планах:**  
  код, наименование, список дисциплин.

- **О дисциплинах:**  
  код, наименование, к какому учебному плану относится, курс, семестр, общее количество часов, количество часов лекций, практических занятий, лабораторных работ, индивидуальных занятий, самостоятельной работы, промежуточной аттестации.

**Правила:**  
- Каждая дисциплина может быть закреплена за несколькими преподавателями.  
- Определенный вид занятий может вести только один преподаватель.  
- *Пример:* лекции – Мишин Е.А., лабораторные – Петров И.И. (не могут вести два преподавателя одновременно). Практические – может вести Петров И.И.  
- Часы индивидуальных занятий распределяются между преподавателями пропорционально их нагрузке.  
- Каждая группа учится по определенному учебному плану. Учебный план содержит минимум список дисциплин с указанием часов по видам занятий (не может быть пустым).

- **О пользователях:**  
  роль, логин, пароль. Ученый секретарь департамента является одним из его преподавателей.

#### Вариант 4. База данных «Абитуриент»

Хранятся сведения о поступающих в вуз абитуриентах, направлениях и специальностях, количестве мест для поступления и т.д.

**Пользователи:** администратор, работник приемной комиссии.

- **Администратор** – добавляет/удаляет/редактирует пользователей системы, имеет неограниченные права.
- **Работник приемной комиссии** – занимается вводом и обработкой данных.

**Правила:**  
- Абитуриент может подать документы на несколько направлений/специальностей и выбрать для каждого направления несколько форм обучения (очная, очно-заочная), вид обучения (бюджетное/платное).  
- Абитуриент может попросить работника приемной комиссии ознакомить его с учебным планом направления/специальности.  
- Учебный план направления/специальности содержит минимум список дисциплин, подлежащих изучению (не может быть пустым).

**Хранимые данные:**

- **Об абитуриенте:**  
  индивидуальный номер, ФИО, паспортные данные, адрес, пол, возраст, данные о медали, участие во всероссийской олимпиаде (призер/победитель заключительного этапа), другие достижения и их наименования, льготы (по целевому направлению, инвалид, сирота, ветеран боевых действий), на какие направления/специальности поступает (в том числе форма, вид обучения), количество баллов ЕГЭ по каждому предмету.

- **О направлениях и специальностях:**  
  код, наименование, количество лет обучения, количество бюджетных мест, количество мест с оплатой обучения, список учитываемых предметов, факультет, департамент, учебный план, конкурс на направление/специальность, форма и виды обучения.

- **Об учебных планах:**  
  код, наименование, направление/специальность, список дисциплин.

- **О дисциплинах:**  
  код, наименование, курс, семестр, к какому учебному плану относится.

- **О пользователях:**  
  роль, логин, пароль.
