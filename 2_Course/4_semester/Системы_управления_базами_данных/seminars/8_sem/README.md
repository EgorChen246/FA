# Задание на 15-16 семинар (8_sem)

## Блок 1 (общие задания для всех)

### Задание 1. Триггер логирования новых самолётов

- Создайте копии таблицы `aircrafts`:  
  - `aircrafts_tmp` – рабочая таблица  
  - `aircraft_log` – таблица для логов
- Создайте **триггер**, который копирует в `aircraft_log` информацию о **каждом новом самолёте**, добавляемом в `aircrafts_tmp`.
- Проверьте работу триггера, сохраните **скриншоты результатов**.

### Задание 2. Триггер каскадного удаления самолёта

- Создайте копии таблиц: `flights`, `aircrafts`, `seats`.
- Напишите триггер, который выполняется **перед удалением** записи из таблицы `aircrafts`.
- Триггер должен:
  - проверить наличие в таблицах `flights` и `seats` записей, относящихся к удаляемому самолёту;
  - если такие записи есть – **удалить их**.
- Проверьте работоспособность триггера, сохраните результаты.

### Задание 3. Автоматическое обновление суммы бронирования

Требуется автоматически обновлять `total_amount` в таблице `bookings` при:
- изменении количества билетов, относящихся к бронированию;
- изменении стоимости билета (`amount` в `ticket_flights`) в бронировании.

- Создайте необходимые триггеры для автоматического обновления суммы бронирования.
- Проверьте работу триггеров, сохраните скриншоты.

> **Примечание:** существует готовое решение в учебных материалах (Postgres Professional, слайды по серверному программированию). Разрешается им воспользоваться.

## Вариант 18. Стоматологическая поликлиника

### Предметная область
Необходимо хранить информацию:
- о **пациентах** (номер пациента, фамилия, адрес, год рождения);
- о **предоставляемых видах услуг** (код, название);
- об **оказании услуг пациентам** (стоимость, время приёма).

### Схема базы данных

| Таблица | Поля | Связи |
|---------|------|-------|
| **Услуги** | Код (PK), название | |
| **Пациенты** | Номер (PK), фамилия, адрес, год рождения | |
| **Оказанные услуги** | Пациент (FK), услуга (FK), время, стоимость | `Услуги.код → Оказанные услуги.услуга`<br>`Пациенты.номер → Оказанные услуги.пациент` |

**Связи:**
- `Услуги — Оказанные услуги`: один ко многим (код → услуга)
- `Оказанные услуги — Пациенты`: один ко многим (пациент → номер)

### 1. Изучение оператора CREATE TRIGGER (триггеры к базовым таблицам)

#### 1.1. AFTER-триггер на удаление из таблицы «Услуги»
Разработать **AFTER-триггер**, который позволяет удалять информацию обо всех услугах из таблицы **Услуги**, **кроме** услуги с кодом `100`.  
*Считать, что пользователю предоставляется возможность удаления множества записей в таблице.*

#### 1.2. Триггер на изменение стоимости
Разработать триггер, который позволяет изменять значение **стоимости** (в таблице «Оказанные услуги») **только на большее значение**.  
*Считать, что пользователю предоставляется возможность модификации множества записей в таблице.*

---

### 2. Создание триггеров для представлений

#### 2.1. Создать представление «Оказанные услуги»
Создать представление с информацией об оказанных услугах.  
Представление должно включать столбцы:

| Столбец | Описание |
|---------|----------|
| номер пациента | из таблицы Пациенты |
| фамилия | из таблицы Пациенты |
| код | из таблицы Услуги |
| название | из таблицы Услуги |
| время | из таблицы Оказанные услуги |
| стоимость | из таблицы Оказанные услуги |

#### 2.2. Триггер для вставки данных через представление
Разработать триггер, который позволяет **вносить информацию об оказанных услугах через представление**.  
- Считать, что пользователю предоставляется возможность вставки **только одной записи** через представление.  
- Предусмотреть вывод сообщения об ошибке в случае ввода информации о **несуществующем пациенте** или **несуществующей услуге**.
