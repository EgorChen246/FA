# Задание на 13-14 семинар (7_sem)

## База данных «Авиарейсы»

Все задания выполняются на основе учебной базы данных «Авиарейсы» (например, демонстрационная БД PostgreSQL).

### Выбор варианта

Вариант выбирается по формуле: (Номер_по_журналу % 4) + 1, где `%` — остаток от деления.

> **Важно:**  
> Все функции/процедуры следует вызывать/выполнять и **документировать результаты**.

## Вариант 1

### Блок 1

1. **Функция «Самый длительный перелёт»**  
   Напишите SQL-функцию, в которую передаётся код самолета. Функция возвращает строку, содержащую через запятые:
   - код самолета,
   - его название,
   - дату отправления,
   - дату прибытия,
   - номер перелёта  
   для **самого длительного перелёта**.

2. **Функция с VARIADIC для перелётов**  
   Напишите SQL-функцию, которая для заданного переменного множества `flight_id` (передаётся с помощью массива `VARIADIC`) выдаёт множество строк, содержащих:
   - наименование аэропорта отправления,
   - планируемую дату отправления,
   - статус полёта,
   - код самолета.

3. **Количество проданных билетов**  
   Напишите SQL-функцию, возвращающую количество билетов, проданных на заданный рейс.

### Блок 2

1. **Копия таблицы `bookings` + процедура**  
   - Создайте копию таблицы `bookings`.  
   - Создайте и выполните SQL-процедуру, которая увеличивает все значения `total_amount` на процент (от соответствующих значений `total_amount`), переданный в функцию в качестве параметра.

2. **Функция с выходными параметрами (билет → пассажир)**  
   Создайте и выполните SQL-функцию с выходными параметрами, в которую передаётся номер билета. Функция возвращает:
   - идентификатор пассажира,
   - имя+фамилию пассажира,
   - контактные данные пассажира  
   в виде **трёх выходных параметров**.

3. **Функция VARIADIC – сумма**  
   Создайте и выполните SQL-функцию c переменным числом аргументов (`VARIADIC`), которая возвращает **сумму** переданных аргументов.

4. **Функция с `fare_cond` → таблица `seats`**  
   Создайте и выполните SQL-функцию с параметром `fare_cond`, которая порождает таблицу из тех строк таблицы `seats`, в которых `fare_conditions = fare_cond`.

5. **Функция с `fare_cond` → множество строк (два варианта)**  
   Создайте и выполните SQL-функцию с параметром `fare_cond`, возвращающую **множество строк** таблицы `seats`, где `fare_conditions = fare_cond`.  
   Реализуйте **два варианта**:
   - с `SETOF <имя_таблицы>`
   - с колонками, определяемыми выходными параметрами (`SETOF RECORD`).

1. **Переменная на трёх уровнях вложенности**  
   Создайте функцию на языке **PL/pgSQL**, в которой переменная с одним и тем же именем объявляется и используется (выводится, ей присваиваются значения) на **трёх уровнях вложенности**. Задокументируйте результаты.

2. **Динамические команды (SELECT, UPDATE, DELETE)**  
   Придумайте и напишите **3 динамически формируемых команды** на языке PL/pgSQL, в которые передаются параметры. Используются запросы:
   - `SELECT`,
   - `UPDATE`,
   - `DELETE`  
   к таблицам из БД «Авиарейсы».  
   *Предварительно создайте копии таблиц, на которых проводятся эксперименты.*  
   В **одной** из команд задайте имя таблицы динамически.

3. **Переписывание SQL-функций в PL/pgSQL**  
   Перепишите на язык **PL/pgSQL** SQL-функции, реализованные по заданиям **4–5 из блока 2**.

4. **Процедура: сравнение дальности самолётов**  
   Напишите процедуру на PL/pgSQL, которая просматривает (в цикле) таблицу `aircrafts_data` и выдаёт **все пары моделей самолётов**, у которых разница между значениями поля `range` **не превышает заданное значение** (передаётся в качестве параметра).

5. **Курсор с параметром (flights + airports дважды)**  
   Изучите тему «Курсоры» ([документация PostgreSQL](https://postgrespro.ru/docs/postgresql/9.6/plpgsql-cursors#plpgsql-cursor-for-loop)).  
   - Создайте курсор с параметром, связанный с запросом, который соединяет `flights` и `airports` (**эта таблица джойнится дважды**) по кодам аэропорта отправления и прибытия.  
   - Используя соответствующую курсорную переменную, пройдите в цикле по строкам результата соединения и выведите все строки, в которых **город отправления равен заданному городу** (заданный город — параметр курсора).
