# Задание на 17-18 семинар (9_sem)

## Общие требования

Создайте в среде разработки на языке **Python** (например, PyCharm) программу, которая реализует следующие задачи, оформленные в виде отдельных функций.

---

## Выбор варианта

Вариант выбирается в соответствии с номером по журналу по формуле: № варианта = (Номер по журналу % 20) + 1, где `%` — операция взятия **остатка от деления**.

---

## Порядок выполнения

### 1. Создание базы данных и таблиц

- Вначале создайте саму базу данных на сервере **PostgreSQL** (с помощью pgAdmin или другого клиента).
- В своей программе реализуйте функцию, которая создаёт структуру базы данных:
  - создаёт **все указанные таблицы** (названия таблиц и столбцов задайте **латинскими буквами**, таблицы — во **множественном числе**, без пробелов, осмысленные);
  - использует команду `CREATE`;
  - предусматривает **целостность данных** (создайте необходимые ключи).

### 2. Функции добавления данных

Для **каждой таблицы** напишите **два варианта** функций:

- **первый вариант** — добавляет **одну** строку данных;
- **второй вариант** — добавляет **все указанные в задании** строки.

> **Важно:**  
> В каждую из функций данные (одна строка или набор строк) передаются **в качестве параметров**.  
> В запросе, который выполняется с помощью `execute()` / `executemany()`, данные также передаются как параметры.  
> Используйте **параметризованные запросы** `INSERT`.

### 3. Функции выборки данных

Для **каждой таблицы** реализуйте следующие виды функций:

- выбрать **все данные** из таблицы;
- выбрать данные, в которых значение(-я) поля(-ей) **равно(-ы) заданному(-ым)** — параметризованные запросы, значения передаются в функцию в качестве параметра(-ов);
- выбрать данные, полученные после **соединения таблиц** (`JOIN`); в запросе должен быть **хотя бы один параметр**.

> Все параметры, присутствующие в запросах, должны передаваться в функцию **при её вызове**.

### 4. Функции обновления данных

Для **каждой таблицы** напишите функции, которые выполняют обновление её полей.

- Предусмотрите выполнение условий **сохранения целостности данных**.
- Значения, которыми нужно обновить данные в таблице, должны передаваться в соответствующую функцию **в качестве параметра**.

### 5. Функции удаления данных

Для **каждой таблицы** напишите функции:

- **а)** удаление данных по **некоторому условию** — значения для условий передавайте в качестве параметров в функцию;
- **б)** удаление **всех данных**.

> Предусмотрите выполнение условий **сохранения целостности данных**.

### 6. Документирование

Выполните **вызовы всех разработанных функций** и **задокументируйте результаты**.
