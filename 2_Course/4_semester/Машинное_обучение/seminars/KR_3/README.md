# Контрольная работа (КР)

## Задания (с баллами и подсказками)

### 1. Загрузка и постановка задачи (1 балл)
- Загрузите предложенный датасет с помощью функции `sklearn.datasets.fetch_openml`.
- Выведите текстовое описание загруженного датасета.
- Определите, какая **бизнес-задача** ставится.
- Переведите бизнес-задачу в **задачу машинного обучения**.

> **Подсказка:**  
> Датасеты бывают на **регрессию** и на **классификацию**.  
> Сначала определите тип датасета, затем формулируйте задачу МО.

---

### 2. Предварительный анализ (1 балл)
- Проведите **предварительный анализ** датасета.
- Выведите основную **статистическую информацию** о данных (`.describe()` и т.п.).
- Проверьте **дисбаланс целевого признака**.

> **Подсказка:**  
> - Для **классификации** – посмотрите количество объектов в каждом классе.  
> - Для **регрессии** – постройте распределение целевой переменной (гистограмму), чтобы увидеть её характер.

---

### 3. Проверка пригодности данных (1 балл)
Убедитесь, что данные пригодны для моделирования:
- **Нет пропущенных значений**.
- **Все признаки численные**.

Если условия нарушаются – **исправьте** это (укажите, каким способом).

> **Подсказка:**  
> Проверьте пропуски (`isnull().sum()`), типы данных.  
> Опишите, как вы обработали проблемы (удаление, заполнение, кодирование и т.д.).

---

### 4. Обучение линейной модели (1 балл)
- Обучите **любую линейную модель**, подходящую для вашей задачи.
- Выведите результат метрики с помощью метода `score()`.
- **Опишите**, какая именно метрика подсчитывается в `score()` для вашей модели.

> **Подсказка:**  
> Для классификации – `LogisticRegression`, для регрессии – `LinearRegression`.  
> `score()` для классификации даёт **accuracy**, для регрессии – **R²**.

---

### 5. Дополнительные метрики (1 балл)
- Подберите **ещё 3 метрики**, подходящие для вашей задачи МО.
- Оцените обученную линейную модель с помощью этих метрик.

---

### 6. Для задач классификации (1 балл)
- Постройте **ROC-кривые** для модели.
- Вычислите **ROC-AUC** (площадь под кривой).
- Найдите **оптимальный порог** модели.

### 6. Для задач регрессии (1 балл)
- Постройте **совместное распределение** теоретических (предсказанных) и эмпирических (фактических) значений целевой переменной (например, scatter plot).
- Сделайте вывод о **наличии или отсутствии систематической компоненты** в отклонениях, об их общей величине.

> **Подсказка для регрессии:**  
> Постройте график `предсказанные vs реальные`. Если точки ложатся вдоль линии `y=x` – хорошо.  
> Оцените, есть ли смещение (bias) и насколько велики ошибки.

---

### 7. Для задач классификации (1 балл)
- Постройте **PR-кривые** (Precision-Recall) для модели.
- Вычислите **PR-AUC**.
- Найдите **оптимальный порог** модели.

### 7. Для задач регрессии (1 балл)
- Постройте **ту же модель**, но с **предварительной нормализацией** признаков (например, `StandardScaler`).
- Сделайте вывод о **влиянии нормализации** на качество работы модели.

---

### 8. Кросс-валидация (1 балл)
- **Обоснуйте** выбор типа разбиения данных при кросс-валидации для вашей задачи.
- Обучите **любую другую модель** (не линейную) с использованием кросс-валидации.

> **Подсказка:**  
> - Если данных **мало** – используйте **Leave-One-Out** или стратифицированную KFold.  
> - Если данных **много** – обычную **K-fold** (например, 5 или 10).  
> - Для классификации с дисбалансом – **StratifiedKFold**.

---

### 9. Диагностика модели (2 балла)
- Проведите **диагностику** любой модели (например, той, что получилась лучше).
- Постройте **кривые обучения** (learning curves).
- Сделайте вывод о **переобученности** или **недообученности** модели.

> **Подсказка:**  
> Используйте библиотеку **Yellowbrick** или `learning_curve` из sklearn.

---

### 10. Влияние гиперпараметров (2 балла)
- Исследуйте, как **любой из гиперпараметров** модели влияет на её эффективность.
- Покажите графики зависимости метрики от значения гиперпараметра.

> **Подсказка:**  
> Выберите любую модель из предыдущих пунктов и подберите для неё параметры (например, `C` в логистической регрессии, `alpha` в гребневой регрессии, `n_neighbors` в KNN и т.д.).

---
