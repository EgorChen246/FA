## Экзамен состоит из: теории и задач

### Теория
1. Чистый приведенный доход: его свойства, методика расчета.  
2. Внутренняя норма доходности: содержание, методика расчета.   
3. Определение срока окупаемости инвестиций.  
4. Время как фактор в финансовых расчетах.Принцип неравноценности денег во времени.  
5. Классификация процентов.  
6. Формула наращения по простым процентам.  
7. Практика начисления простых процентов.  
8. Простые переменные ставки.  
9. Реинвестирование по простым процентным ставкам.   
10. Банковский или коммерческий учёт.  
11. Наращение по учётной ставке.  
12. Сравнение ставки наращения и учётной ставки. Прямая и обратная задачи.   
13. Совмещение начисления процентов по ставке наращения и дисконтирования по учётной ставке. 
14. Формула наращения по сложным процентам. 
15. Сравнение наращения по простым и сложным процентам.  
16. Номинальная процентная ставка.  
17. Эффективная процентная ставка.    
18. Эквивалентные процентные ставки.  
19. Конвертация валюты и начисление процентов.  
20. Формула наращенной суммы с конвертацией валюты.   
21. Потоки платежей и финансовые ренты(аннуитеты).  
22. Финансовые ренты (аннуитеты) и их основные параметры.  
23. Классификация финансовых рент.  
24. Обобщенные параметры потоков платежей. Расчет современной стоимости постоянной p-срочной ренты постнумерандо.  
25. Лизинг, как один из видов производственных инвестиций.
